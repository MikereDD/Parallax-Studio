# Parallax Studio v1.0-dev.4.3 Theme Correction Test

1. Run `./build.ps1 -Bootstrap -InstallBootstrapTools -Run` from a fresh source folder.
2. Open a video, then open Tracks. Confirm the entire panel stays dark with readable text.
3. Check Audio, Subtitles, and Chapters, including a file with no chapters. Confirm a themed empty state appears instead of a white panel.
4. Open both title-bar selectors. Confirm closed and popup states remain themed and readable.
5. Switch through every theme and each typography profile while the tracks panel is open.
6. Verify selected, hover, and disabled states remain easy to distinguish.
7. Confirm playback, seeking, track switching, subtitles, chapters, and clean shutdown still work.
