# Parallax Studio branding assets

The current Parallax Studio application mark uses a dark cinematic `P`, an inset play symbol, layered/parallax rings, and a film-strip element. The design was created specifically for Parallax Studio and adopted during the v1.0-dev.5.5.5 development cycle.

Tracked assets:

- `parallax-studio-icon-source.png` — 1024×1024 master raster used to derive the committed icon sizes.
- `parallax-studio-icon-512.png`
- `parallax-studio-icon-256.png` — README and current WPF title-bar resource.
- `parallax-studio-icon-128.png`
- `parallax-studio-icon-64.png`
- `parallax-studio-icon-48.png`
- `parallax-studio-icon-32.png`
- `parallax-studio-icon-16.png`
- `parallax-studio.ico` — multi-resolution Windows application icon.

The project file uses `parallax-studio.ico` as the executable icon. Keep the 1024×1024 source asset when regenerating smaller variants so the icon family remains consistent.
